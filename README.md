# Malelo · Registro de service

- `index.html?v=CODIGO`: lo que ve el cliente al escanear el QR.
- `sticker.html?v=CODIGO`: sticker con QR para imprimir.
- `taller.html`: carga de service (con PIN). Se instala como app desde Safari o Chrome.
- `config.js`: dirección de la planilla (Apps Script) que guarda los datos.

Los datos viven en la planilla de Google "Malelo – Service vehículos". Esta página solo los muestra y los carga.
